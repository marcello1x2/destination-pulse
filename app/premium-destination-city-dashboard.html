Method note

Transparent by design

Questa dashboard è già strutturata come prodotto reale: dati caricati in JSON, scoring separato, UI pronta per sostituire i proxy con feed live. Nella fase successiva il file JSON potrà essere generato da script Python o pipeline schedulata senza riscrivere la pagina.

Sources intended for live integration: World cities registries derived from GeoNames-style datasets, World Bank Indicators API v2, OpenAQ locations API, OSM/Overpass or Places APIs.
